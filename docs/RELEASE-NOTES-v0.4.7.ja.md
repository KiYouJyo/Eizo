# Eizo v0.4.7

## 設定画面の実機能接続

Eizo 0.4.7 では設定画面を「一般 / メタデータ / 再生」の3ページへ整理し、表示だけの項目を廃止しました。残した設定はすべて永続化され、実際の実行経路へ接続されています。

### 主な変更

- 設定画面を「一般 / メタデータ / 再生」の3ページへ簡素化。
- 一般には表示言語、外観、Bangumi アカウントを集約。
- 「日本メディア表示」など説明中心の設定を削除し、タイトル表示はアプリ内部で表示言語に応じて自動処理。
- メタデータに、スキャン完了後の自動取得、画像補完、ライブラリ再取得、Metadata キャッシュ削除を追加。
- 自動取得は既存の「スキャン → 独立 Metadata ジョブ」構成を維持し、ネットワーク処理をファイルスキャンへ再結合しない設計。
- 再生に、次エピソード自動再生、再生速度記憶、既定速度、優先音声言語、優先字幕言語を追加。
- 字幕記憶は Track ID ではなく、作品単位の内蔵/外部種別・言語・名称特徴を保存。
- Metadata がある作品は Provider + SubjectId、未解決作品は Recognition のタイトル/年を作品キーとして使用。
- 主/副字幕の位置と背景透明度を設定画面から変更可能にし、プレイヤーと同じ永続設定を共有。
- 简体中文 / 日本語 / English の3言語リソースを同期。

## 検証

0.4.7 の受け入れテストでは、設定 UI/実行時契約、音声・字幕設定、独立 Metadata 自動連携、Recognition/Metadata/Cache/Bangumi/WebDAV 回帰、Release x64 ビルド、署名済み MSIX のインストール/起動、プロトコル起動、独立コンポーネントの実呼び出しフォールバック、one-click パッケージを検証します。
