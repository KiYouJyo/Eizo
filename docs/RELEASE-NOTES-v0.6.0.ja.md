# Eizo v0.6.0

## プレーヤーと詳細画面の改善

0.6.0 では、プレーヤー操作、作品詳細画面のファーストビュー、更新管理 UI をまとめて改善し、フレームプレビュー機能を Playback ランタイムへ正式に統合しました。

## 変更内容

- 作品詳細 Hero をホーム画面と同じ横長 2 カラム構成へ変更。左側に情報と操作、右側に横長 Backdrop を表示します。
- Hero の高さを固定してコンパクト化し、エピソード、キャスト、スタッフ情報をより早く表示。
- 「メタデータを再取得」「手動で照合」を直接表示し、オーバーフローメニューから分離。
- 全画面コントロールの表示時間を 2 / 4 / 6 / 10 秒から選択可能。
- 全画面で左右キーを短押しすると 10 秒戻る / 進む。長押しでは左 0.5×、右 2× の一時速度になり、離すと元の速度へ戻ります。
- 全画面サイドバーを開閉した後に再生コントロールが操作不能になる問題を修正。
- タイムラインの数値 Tooltip を廃止し、実デコードフレームのプレビューを追加。Slider/Thumb が処理済みのポインターイベントも取得するようにしてドラッグ検出を安定化。
- Playback 0.2.3 へ更新し、バックエンド非依存のフレームキャプチャ機能を追加。
- 更新管理画面では Eizo と Metadata の列幅・ボタン幅を統一したまま維持。
- Metadata カードに「リリースノート」ボタンを追加。更新確認済みの場合は該当 Eizo.Metadata Release を、未確認の場合は Releases 一覧を開きます。

## 互換性

- Windows 10 2004 / Windows 11、x64。
- Eizo.Metadata / Eizo.Playback の独立更新構成を継続します。
