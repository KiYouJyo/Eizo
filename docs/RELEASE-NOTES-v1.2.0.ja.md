# Eizo v1.2.0

## 統一カードデザインとキャッシュ管理

Eizo 1.2 ではカード UI を構造的に整理しました。メディアライブラリと「マイコレクション」は類似した XAML を個別に持たず、同じカードコンポーネント、寸法、インタラクション状態を共有します。動画キャッシュには右クリック操作も追加しました。

## 変更内容

- ポスターカードの寸法、角丸、枠線、ホバー、押下、キーボードフォーカス、文字階層を共通リソースへ統合。
- 再利用可能な `MediaPosterCard` を追加し、メディアライブラリと Bangumi の「マイコレクション」で共用。
- 「マイコレクション」のホバー表示がカード本体とずれていた問題を修正し、ハイライトの範囲と角丸をカード境界に一致。
- ライブラリではソース診断情報を通常表示しないまま維持し、「マイコレクション」では同じカードの任意フッター行に視聴進捗を表示。
- 動画キャッシュ一覧も共通の横長カードスタイルを利用し、カード全体で右クリックメニューを開けるように変更。
- 右クリックメニューに「ファイルの場所を開く」と「キャッシュを削除」を追加。
- 「ファイルの場所を開く」は対象キャッシュブロックのフォルダーを優先し、まだ完全なキャッシュグループがないダウンロードでは Eizo のキャッシュルートへフォールバック。
- 「キャッシュを削除」は確認ダイアログを表示せず即時実行し、危険操作の視覚スタイルを維持。
- v1.2 カード UI 回帰契約を追加し、リポジトリ検証に組み込み。
- 製品 / MSIX バージョンを 1.2.0 / 1.2.0.0 に更新。

## 確認ポイント

- ライブラリと「マイコレクション」の同サイズカードで、外枠・角丸・操作フィードバックが一致すること。
- 「マイコレクション」のホバー表示がカード本体からはみ出したり縮んだりしないこと。
- キャッシュカードの任意位置を右クリックして「ファイルの場所を開く / キャッシュを削除」が表示されること。
- 削除時に確認ダイアログが表示されないこと。
- ライト / ダークテーマとキーボードフォーカス時にもカード境界が統一されること。

## 対応環境

- Windows 10 2004 / Windows 11
- x64
