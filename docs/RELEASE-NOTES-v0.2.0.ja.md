# Eizo v0.2.0 安定性・3言語・アプリ内更新

- ダークモードがまれに不正表示になる問題を修正し、ウィンドウルートをテーマの単一管理点に統一しました。システム追従・ライト・ダークの即時切り替えは引き続き利用できます。
- 極端なウィンドウ縮小時のレスポンシブレイアウトを再構成し、ホーム／カテゴリ画面の不安定な自動グリッド経路を廃止しました。タブは SpatialViewer と同じ適応方式へ戻し、極小サイズと高速連続リサイズの回帰テストを通過しています。
- 简体中文・日本語・English の実行時切り替えを完成し、「システム設定に従う」にも対応しました。切り替え時はキャッシュ済みページとタブ文字列も更新されます。
- GitHub Releases ベースのアプリ内更新を実装しました。更新確認、ダウンロード、SHA-256 検証、MSIX 署名検証、インストール、再起動までをアプリ内で処理します。更新ボタンは状態に応じて変化し、常設の独立再起動ボタンはありません。
- UrbanPlanToolbox と同じ方式で単一インスタンス起動を導入しました。起動中にアプリアイコンを再度クリックしても新しいウィンドウを作らず、既存ウィンドウを前面へ戻します。
- 最後の通常ウィンドウサイズと最大化状態を保存し、次回起動時に復元します。現在のディスプレイ作業領域を超える場合は安全にクランプします。
- x64 GitHub 配布契約として、署名済み MSIXBundle、軽量 one-click パッケージ、SHA256SUMS.txt を継続提供します。
- v0.2.0 はアプリシェル、安定性、基盤機能を中心とするリリースです。メタデータ取得、メディアソース、Eizo.Playback 再生アダプターは後続バージョンで接続します。
