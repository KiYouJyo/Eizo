# Eizo v0.2.1 播放器体验、Eizo.Playback 集成与稳定性修复

- 正式接入 Eizo.Playback 播放层：Eizo UI 继续与 LibVLCSharp 类型隔离，并通过固定版本与固定提交恢复本地 NuGet 包，保证主仓库构建可复现。
- 完成播放器页面的大幅重构，接入真实媒体播放、播放/暂停、Seek、章节、字幕与音轨入口、倍速、音量和全屏等基础控制。
- 新增音量按钮与滑块；全屏状态下可使用鼠标滚轮按 5% 步进快速调整音量。
- 重做全屏控制区：空闲时自动隐藏，鼠标移动或操作时重新显示；修正控制区对齐和全屏状态下的交互。
- 重做右侧播放队列/字幕音轨边栏：全屏使用 Overlay + 点击外部关闭，非全屏保持常驻 Inline 行为，避免普通模式误触收起。
- 浅色主题进入全屏后，播放器控制区、浮层与边栏统一切换为深色体验；退出全屏后恢复原有浅色界面。
- 修复浅色普通模式下边栏背景和播放器中央状态提示的主题异常。
- 重构播放器标签页和全屏退出生命周期：关闭视频标签前先释放播放 Surface/LibVLC/D3D 资源，并避免视觉树卸载期间同步切换窗口 Presenter，降低退出全屏与关闭播放标签时的卡死风险。
- 增强播放状态持久化与分类页内容，播放器标签页切换后继续保留媒体上下文和播放位置。
- 关于页移除尚未具备安全独立部署能力的 Eizo.Playback 独立更新卡片；Eizo.Playback 继续作为独立开发仓库，由 Eizo 版本固定集成，不向用户提供伪独立更新。
- 保持 x64 GitHub 发行合同：签名 MSIXBundle、one-click 安装包与 SHA256SUMS.txt。
