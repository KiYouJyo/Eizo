# Eizo v0.3.1 WebDAV メディアソース管理と Bangumi ナビゲーション再構成

Eizo v0.3.1 ではローカル / WebDAV メディアライブラリをさらに整備し、今後の Bangumi 視聴管理・新番情報連携に向けたナビゲーションとページ構造を追加しました。

## メディアソースと WebDAV

- WebDAV メディアソース編集を完成し、名前・アドレス・ユーザー名・パスワードを変更できるようにしました。
- パスワード欄を空にした場合は既存資格情報を保持し、機密情報は引き続き Windows PasswordVault に保存します。
- 「メディアソースを編集」と「読み込みフォルダーを編集」を独立した操作に分離しました。
- WebDAV フォルダー選択画面をネイティブ WinUI ウィンドウとして再構成し、Mica、BreadcrumbBar、フォルダーアイコン、複数選択、ダブルクリック移動に対応しました。
- 1つの WebDAV ソースに複数のスキャンルートを保存でき、選択範囲に基づいてカタログを構築します。
- 各ソースカードに「今すぐスキャン」を追加し、スキャンを非同期化しました。ソース追加・編集時の自動スキャンは行いません。
- スキャン中はネイティブ ProgressRing を表示し、通常時はボタンをコンパクトに保ちます。
- 冗長な「接続をテスト」と「開いたローカル動画」疑似ソースカードを削除しました。

## UI とテーマ修正

- ライトテーマでの編集ダイアログ、フォルダー選択画面、一部文字色の不整合を修正しました。
- WebDAV フォルダー画面のタイトルバーとコンテンツ表面を統一し、表示できるフォルダー数を増やしました。
- メディアソースカードのテンプレートを再構成し、実際の表示面に角丸が適用されるよう修正しました。
- 「今すぐスキャン」の文字配置と通常 / スキャン中のサイズ変化を修正しました。

## ナビゲーション

- ハンバーガーメニューを「ホーム → Bangumi → メディアライブラリ」に整理し、キャッシュ・情報・設定を下部に固定しました。
- Bangumi 親項目自体を「視聴リスト」総合ページへの入口とし、子項目は「放送カレンダー / 新番 / ランキング・発見」の3つにしました。
- メディアライブラリ親項目は従来どおり総合カタログを開き、子項目を「アニメ / 映画 / ドラマ / メディアソース」に整理しました。
- 総合カタログのページ見出しを「分類」から「メディアライブラリ」に変更しました。
- Bangumi 用ワークスペースルートとネイティブ WinUI プレースホルダーページを追加し、今後の公式アカウントログイン、視聴同期、放送カレンダー、新番データ連携に備えました。
- v0.3.1 ではナビゲーションとページ予約のみで、Bangumi アカウントログインやオンラインデータ連携はまだ有効化していません。

## 安定性と互換性

- 既存のプレイヤー、タブ、単一インスタンス、ウィンドウサイズ保存、WebDAV 再生、メディアカタログ動作は維持しています。
- ナビゲーション情報構造の回帰テストを追加し、既存入口の欠落や「視聴リスト」の重複追加を防止します。
- 简体中文 / 日本語 / English の3言語リソース整合性を維持しています。
- 正式配布物は署名済み x64 MSIXBundle、one-click インストーラー、SHA256SUMS.txt を引き続き提供します。
