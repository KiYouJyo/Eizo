# Eizo v0.5.12

## Real Content UI / Close-out：実コンテンツ UI 仕上げ

0.5.12 は既存の UI フレームワークを維持し、0.5.9–0.5.11 で接続した実データを通常利用向けの表示状態へ仕上げます。AniList の追加や大規模なレイアウト変更は行いません。

## 変更内容

- ライブラリカードから認識信頼度やソース/ファイル情報などの開発向け表示を除去。
- 作品カードの右クリックには「再取得 / 手動照合 / 手動照合解除」を残し、通常メニューから認識・メタデータのデバッグ項目を除去。
- 作品単位のメタデータ操作に進行中・成功・警告・失敗の状態表示を追加。
- 詳細ページで原題、年、メタ情報、概要がない場合は項目自体を非表示にし、重複タイトルや “-” のプレースホルダーを表示しないよう変更。
- 詳細ページの再取得/手動照合にも状態表示を追加。
- 選択中シーズンに再生可能な実メディアがない場合の空状態を追加。
- 旧 title-only 詳細画面からサンプルのシーズン、エピソード、Sample ソースを除去。
- ホームの単独/未集約メディアは旧サンプル詳細へ遷移せず、実ファイルの直接再生のみを維持。
- ホーム Hero は欠損している副題・メタ情報・概要を非表示にし、空ライブラリでは不要な操作ボタンを表示しません。
- Sample Movie などのデモデータを含んでいた未使用の旧 CategoryView を削除しました。

## 範囲

- メディアライブラリ/詳細ページの基本レイアウトは変更しません。
- AniList は引き続き対象外です。
- 診断用の認識レポート出力は維持しますが、診断情報は通常 UI に表示しません。
