# Eizo v1.3.0

## ネイティブアニメ検索・インデックス

Eizo 1.3 では Bangumi の「アニメログ」独立ページを削除し、そのナビゲーションをネイティブ WinUI 3 の「アニメ検索」へ置き換えました。Web ページは埋め込まず、Bangumi のアニメ索引データを Eizo の UI で直接表示します。

## 変更内容

- 「アニメログ」ページ、ナビゲーション、ワークスペースルート、専用 UI を削除。
- WinUI 3 の `AutoSuggestBox` を使った「アニメ検索」を追加。
- 分類、原作、ジャンル、地域、対象、年の 6 グループをネイティブ `RadioButtons` で絞り込み可能。
- ランキング、人気、評価、一致度による並び替えを追加。
- Bangumi 検索を `meta_tags`、`tag`、`air_date` 条件へ拡張し、アニメ・非 NSFW に限定。
- 検索結果は既存の `MediaPosterCard` と共通カードスタイルを再利用。
- 初期表示はキャッシュ対応の総合ランキングを継続し、検索・絞り込み時は Bangumi のアニメ索引を直接検索。
- カードを開くと既存の Bangumi 作品詳細へ移動し、コレクション、コメント、関連作品などの流れを維持。
- カードタイトルは原題を優先し、中国語名を補助タイトルとして表示。
- v1.3 用アニメ索引回帰契約と Bangumi 高度検索テストを追加。
- 「ランキングと発見」を「アニメ検索」の直下へ移動し、検索アイコンと重複しない専用の発見/スターアイコンへ変更。
- アニメ検索の6種類の絞り込みを右サイドバーから結果上部の横並びグループへ移動。
- 「さらに読み込む」ボタンを廃止し、末尾までスクロールすると次の50件を自動読み込み。
- 埋め込み字幕がある場合は第1字幕セレクターを埋め込み字幕専用にし、第1字幕の位置・背景コントロールは無効のまま「この動画には内蔵字幕があります。この字幕のスタイルは変更できません。」と表示。外部字幕は第2字幕から選択するよう変更。
- 全画面で左右キーを長押しした一時倍速は下部コントロールを表示せず、画面上部中央の半透明バナーで速度を表示。
- 全画面 / ウィンドウ表示のどちらでも、映像領域のクリックで再生 / 一時停止を切り替え可能。
- 製品 / MSIX バージョンを 1.3.0 / 1.3.0.0 に更新。

## 確認ポイント

- Bangumi ナビゲーションから「アニメログ」が消え、「アニメ検索」が表示されること。
- WebView / WebView2 を使用しないこと。
- 検索、並び替え、上部の6種類の絞り込み、カード、自動ページングが WinUI 3 ネイティブ UI であること。
- 絞り込み条件が Bangumi subject search のアニメ種別・タグ・年へ正しく渡ること。
- 検索結果から既存の Bangumi 作品詳細を開けること。

## 対応環境

- Windows 10 2004 / Windows 11
- x64
