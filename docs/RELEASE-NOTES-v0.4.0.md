# Eizo v0.4.0

## 播放器内容增强验收版

- 播放队列接入真实媒体库聚合集数，不再使用演示队列。
- 队列点击可真实切换播放源，播放结束自动续播下一项。
- 无章节媒体的上一章节/下一章节按钮自动切换为上一集/下一集。
- 自动发现本地及 WebDAV 同目录外挂字幕。
- 支持 SRT、VTT、ASS、SSA 外挂字幕。
- 主字幕继续由 Eizo.Playback / LibVLC 管理；新增独立第二字幕叠加层，实现双字幕。
- 第二字幕跟随播放、拖动进度与换集同步刷新。
- 保留 Playback 独立组件、Recognition/Metadata 独立组件与 bundled fallback 架构。

本验收包用于 0.4.0 播放器功能实机测试。
