# Eizo v1.2.1

## 手動動画キャッシュの単一ファイル化

Eizo 1.2.1 は「手動で動画をキャッシュする」経路だけを変更します。ユーザーが明示的にキャッシュした動画は、多数の 4 MB `.blk` ファイルではなく、元のコンテナ拡張子を持つ1本の完全なメディアファイルとして保存されます。通常再生時の自動プリキャッシュ / ランダムアクセスキャッシュは従来どおり分割方式を使います。

## 変更内容

- 手動キャッシュ専用の `manual-video:` グループを追加し、自動再生キャッシュから分離。
- WebDAV Range による分割ダウンロード、停止 / 再開、進捗、速度表示は維持しつつ、各 Range は1つの一時ファイルへ順次書き込み。
- 完了後に単一のメディアファイルとして登録し、`.mkv`、`.mp4`、`.webm` など元ファイルの拡張子を保持。
- 自動再生キャッシュに同じ Range が存在する場合は再利用してネットワーク再取得を削減。ただし手動キャッシュ自体は単一ファイルのまま。
- 完了した手動キャッシュはローカルファイルから直接再生。旧バージョンの分割オフラインキャッシュも互換再生を維持。
- 容量集計、自動クリーンアップ保護、右クリックでフォルダーを開く操作、削除は既存の統一キャッシュインデックスを継続利用。
- 既存の `.blk` 手動キャッシュはアップデート時に強制変換しません。大容量コピーを起動時に発生させないためで、削除して再キャッシュすると単一ファイルになります。
- 通常の WebDAV 再生キャッシュは変更せず、小さなブロックによるランダムアクセスと作業領域回収を維持。

## 確認ポイント

- 新しい手動キャッシュでは `Cache\media` 内に対象動画の完全なメディアファイルが1つだけ生成されること。
- 拡張子が WebDAV の元ファイルと一致すること。
- キャッシュ完了後、オフラインでもそのファイルから再生できること。
- 手動キャッシュを削除すると完全ファイルも削除されること。
- 通常の WebDAV オンライン再生では従来の `.blk` 自動キャッシュが引き続き動作すること。

## 対応環境

- Windows 10 2004 / Windows 11
- x64
