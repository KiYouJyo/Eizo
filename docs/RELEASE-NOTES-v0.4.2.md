# Eizo v0.4.2

## Bangumi 公开内容接入

- 新增独立 `Eizo.Bangumi` 数据层，Bangumi 网络内容与本地 `Eizo.Metadata` 刮削职责保持分离。
- “放送日历 / 新番 / 排行与发现”从占位页面切换为真实 Bangumi 数据；“我的追番”继续保留到后续账号接入版本。
- 新番页按完整季度读取三个自然月的 TV 动画并去重，支持上一季 / 下一季 / 回到本季。
- 排行与发现支持综合排名、本季排名、本年排名；综合与本年排名支持继续加载下一页。
- 放送日历接入公开 `/calendar`，默认定位今天，并保留星期切换。
- 点击作品可进入 Eizo 内部 Bangumi 条目详情页，查看封面、标题、首播日期、集数、评分、排名、收藏量、简介与标签，并可跳转 Bangumi 原页面。
- 首页“本季新番”不再使用硬编码示例，改为读取当前季度 Bangumi 数据；“查看全部”直接进入新番页。
- Bangumi 数据加入本地缓存：日历 30 分钟、排行 2 小时、季度 6 小时、详情 24 小时；网络失败时可回退到已有旧缓存。
- API 请求使用符合 Bangumi 要求的 Eizo 0.4.2 User-Agent，并保持公开 API 单页最大 50 条限制。
- 新增 Bangumi JSON/parser 单元测试、公共集成契约和真实公网 API smoke workflow。
- 不包含账号登录、收藏写入、观看进度同步或 Bangumi Subject 与本地媒体库自动绑定；这些功能留待后续版本。

本版本继续回归验证 Eizo 0.4.1 媒体库分库、Metadata 外置运行时以及 Eizo 0.4.0 播放队列 / 外挂字幕 / 双字幕能力。
