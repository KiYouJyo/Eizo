# Eizo v0.4.7

## 设置页实际接入

Eizo 0.4.7 将设置页从展示型界面收口为三个真实配置页面：常规、元数据和播放。所有保留项目均连接到持久化设置与实际运行链，不再放置纯说明或凑数项目。

### 主要更新

- 设置页精简为“常规 / 元数据 / 播放”三个页面。
- 常规页保留界面语言、外观与 Bangumi 账户。
- 删除“日本媒体显示”等纯规则型设置；标题显示规则由应用内部按语言自动处理。
- 元数据页新增扫描完成后自动启动独立刮削、图片补全、全库重新刮削和 Metadata 缓存清理。
- 自动刮削保持“扫描任务 → 独立 Metadata 任务”的既有架构，不把网络刮削重新耦合进文件扫描。
- 播放页新增自动下一集、记住播放速度、默认倍速、首选音轨语言、首选字幕语言和首选第二字幕语言。
- 主字幕记忆改为作品级语义偏好：保存内封/外挂类型、语言与名称特征，不保存跨集不稳定的 Track ID。
- 有 Metadata 时以 Provider + SubjectId 建立作品键；未刮削作品回退到 Recognition 标题/年份。
- 设置页可直接修改主/副字幕位置与背景透明度，并与播放器现有参数共用同一持久化设置。
- 三语资源（简体中文 / 日本語 / English）同步完成。
