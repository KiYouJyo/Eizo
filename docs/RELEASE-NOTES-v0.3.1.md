# Eizo v0.3.1 WebDAV 媒体来源管理与 Bangumi 导航重构

Eizo v0.3.1 继续完善本地 / WebDAV 媒体库，并为后续 Bangumi 追番与新番资讯接入完成导航和页面结构预留。

## 媒体来源与 WebDAV

- 完成 WebDAV 媒体来源编辑：可修改名称、地址、用户名与密码，并在验证成功后安全保存。
- 密码留空时保留已有凭据；继续使用 Windows PasswordVault 存储敏感信息，不在界面中回显已保存密码。
- 将“编辑媒体来源”和“编辑读取文件夹”拆分为两个独立流程，修改读取范围时不会误改连接信息。
- 重做 WebDAV 文件夹选择器：使用原生 WinUI 窗口、Mica、BreadcrumbBar、文件夹图标、多选与双击进入。
- 一个 WebDAV 来源可以保存多个扫描根目录，并按选定范围构建媒体目录。
- 新增每个来源卡片上的“立即扫描”，扫描改为异步执行；新增或编辑来源后不再自动触发全量扫描。
- 扫描中显示原生 ProgressRing；空闲时按钮保持紧凑，扫描状态下才扩展显示进度文本。
- 移除冗余的“测试连接”和已打开本地视频伪来源卡片，简化媒体来源页面。

## UI 与主题修复

- 修复浅色模式下编辑弹窗、文件夹选择器与部分文字的深浅色异常。
- 统一 WebDAV 文件夹窗口标题栏和内容区表面颜色，并扩大窗口高度以显示更多目录。
- 重做媒体来源卡片模板，让圆角作用于真实可见表面，同时保留原生 PointerOver / Pressed 状态。
- 修复“立即扫描”文字居中问题，并保持空闲/扫描状态的尺寸逻辑一致。

## 导航结构

- 汉堡菜单调整为“主页 → Bangumi → 媒体库”，缓存、关于、设置固定在底部。
- Bangumi 父项本身直接进入“我的追番”总页，并保留“放送日历 / 新番 / 排行与发现”三个子入口。
- 媒体库父项继续直接进入总媒体目录，子入口为“动漫 / 电影 / 电视剧 / 媒体来源”。
- 媒体库总页标题由“分类”统一改为“媒体库”。
- 新增 Bangumi 四类工作区路由与原生 WinUI 占位页，为后续官方账户登录、追番同步、放送日历和新番数据接入预留结构。
- 本次仅完成导航与页面预留，Bangumi 账户登录和在线数据尚未在 v0.3.1 中启用。

## 稳定性与兼容性

- 保持既有播放器、标签页、单实例、窗口尺寸持久化、WebDAV 播放与媒体目录逻辑不变。
- 新增导航信息架构回归合同，防止后续开发误删既有媒体入口或重新加入重复的“我的追番”子入口。
- 保持简体中文、日本語、English 三语资源一致。
- 正式发行资产继续提供签名 x64 MSIXBundle、one-click 安装包和 SHA256SUMS.txt。
