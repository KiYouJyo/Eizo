# Eizo v0.3.2 播放器稳定性与控制修复

Eizo v0.3.2 重点处理播放器并发、生命周期和高频操作下的稳定性问题，并完善全屏与快捷键控制。本次不继续追踪 WebDAV 播放加载卡片显示问题，该问题作为已知问题保留到后续版本。

## 播放器稳定性

- 重构播放操作串行化逻辑，降低打开媒体、切换字幕、定位、播放状态回调相互竞争时发生卡死或状态错乱的概率。
- 增加播放会话取消与生命周期保护，页面卸载或引擎释放时避免旧任务继续触碰已替换的播放实例。
- 修正播放器表面初始化、释放和重新附着过程中的竞态条件，降低切换标签页与页面生命周期变化导致的挂起风险。
- 补齐 Eizo.Playback 的 `PlaybackOperationQueue` 与诊断跟踪基础设施，并修复干净环境首次恢复依赖时的误判问题。
- 为并发操作加入回归测试，并切换到 .NET 10 的 Microsoft Testing Platform 测试模式。

## 字幕与播放控制

- 修复字幕轨高频切换时因 ComboBox 数据重建造成的 WinUI 崩溃风险。
- 字幕、音轨等选择操作改为保留最新用户意图，过时的等待操作会被取消。
- 增加窗口级空格键播放 / 暂停。
- 全屏状态支持 ESC 退出，并加强全屏切换时的状态隔离。
- 合并高频播放位置 UI 更新，减少不必要的主线程压力。

## 构建与发布

- 修复 Eizo.Playback 固定依赖补丁在全新 `--no-checkout` 工作区中的恢复流程。
- Release x64、并发测试、MSIX 构建和签名链路已验证通过。
- 正式发行继续提供签名 x64 MSIXBundle、one-click 安装包和 SHA256SUMS.txt。

## 已知问题

- **WebDAV 视频开始播放时，加载状态卡片仍可能不显示。** 本版本暂时放弃继续修复该 UI 问题；视频播放本身不以该卡片作为成功条件，后续将单独重新梳理加载状态模型。
