# Eizo v0.3.0 — WebDAV メディアソースとリモート再生

v0.3.0 では、Eizo をローカル再生基盤の段階から、実際に利用できるリモートメディア再生へ進めました。最初の重点メディアソースは WebDAV です。

## WebDAV メディアソース

- メディアソース Provider を独立した構成へ整理し、ローカルソースと WebDAV ソースを別々に登録するようにしました。今後のクラウド／リモートソース追加にも対応しやすい構造です。
- WebDAV メディアソースの追加・保存・管理に対応しました。認証情報は Windows PasswordVault に保存し、Credential インターフェース経由で Provider から分離しています。
- 認証付き PROPFIND、ディレクトリ解析、リモートメディア検出に対応し、401 / 404 / Range リクエストを含む実行時回帰テストを追加しました。
- WebDAV が絶対パス形式の href を返す場合の URL 解決を修正し、現在の HTTP(S) origin に正しく解決するようにしました。
- 未解析カタログでは、リモート動画の実際の拡張子を表示します。

## リモート再生

- Eizo.Playback を 0.2.1 へ更新し、認証情報付きネットワークメディアのオープン経路を統合しました。
- WebDAV で検出した動画を Eizo プレイヤーから直接再生できます。
- リモート動画の再生、シーク、再生速度変更を実機経路で確認済みです。
- HTTP Range リクエストに対応し、認証失敗やリソース不存在などのエラーパスもテストしています。

## プレイヤー／メディアソース UI

- メディアソース一覧を単純な文字列行からカード UI へ変更しました。
- 読み込み表示を Mica surface + WinUI 標準 ProgressRing に変更し、進捗とリアルタイムのダウンロード速度を表示します。
- 再生速度スライダーのラベルと実際の位置がずれていた問題を修正しました。
- サイドバー下部の重複した再生情報を削除しました。
- 下部コントロールから重複した音声／字幕切替を削除し、右側の「字幕と音声」領域へ統合しました。
- プレイヤー内の「ローカル動画を開く」入口を削除し、選択済みメディアの再生に専念する構成へ整理しました。
- プレイヤー UI の整理内容を守る契約テストと CI ガードを追加しました。

## バージョンと配布

- ユーザー向けバージョンは **v0.3.0** のままです。
- Windows パッケージバージョンは **0.3.0.1** です。末尾の 1 は WebDAV 認証・再生修正後のパッケージリビジョンです。
- GitHub Release では、署名済み x64 MSIXBundle、one-click パッケージ、SHA256SUMS.txt の 3 つを引き続き正式配布します。
