# Eizo v0.6.1

## Application Visual Asset Refresh

Eizo 0.6.1 fully refreshes the Windows app icon, MSIX visual resources, and Microsoft Store listing artwork. Existing UI layout, business logic, and functionality are unchanged.

## Included

- Update the multi-size `Eizo.ico` used by the EXE, shortcuts, and installer.
- Replace AppList, Square44, Square150, Square71, Square310, Wide, StoreLogo, SplashScreen, and every supplied DPI/theme variant.
- Enable AppList, Windows 10 compatibility tiles, and splash-screen resources in the MSIX manifest.
- Add square, poster, and Super Hero artwork for the Microsoft Store listing.

## Compatibility

- Windows 10 2004 / Windows 11, x64.
