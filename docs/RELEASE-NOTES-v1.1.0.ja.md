# Eizo v1.1.0

## ネイティブ ピクチャー イン ピクチャーと再生体験の改善

Eizo 1.1 では Windows App SDK の CompactOverlay を利用したネイティブ PiP を追加し、再生エンジンを作り直さずに現在のセッションを維持します。

## 変更内容

- プレイヤーヘッダー右側に PiP ボタンを追加し、WinUI の標準 Button と Segoe Fluent の MiniExpand アイコンを使用。
- PiP 移行時も現在の PlaybackView をそのまま維持し、LibVLC エンジンをアンロード / 再生成しないため、メディアを開き直しません。
- PiP と全画面は相互排他。小窓ではアプリのタイトルバー、ナビゲーション、プレイヤーサイドバーを隠し、高頻度の再生操作だけを残します。
- 10 秒戻る、再生 / 一時停止、10 秒進む、通常ウィンドウへ戻る操作を提供し、WinUI 標準のホバー / 押下 / フォーカス状態をそのまま利用。
- 再生中は PiP コントロールを自動非表示にし、マウス移動で再表示。コントロール上にポインターがある間は表示を維持。
- Escape で PiP を終了でき、PiP 内のマウスホイールで音量を調整可能。
- 小窓向けに外部字幕の文字サイズと余白を縮小し、終了時に元の字幕 / レイアウト設定へ復元。
- PiP 前のウィンドウ位置、サイズ、最大化状態を保存し、終了後に復元。Windows 側で CompactOverlay が解除された場合も Eizo の UI 状態を同期。
- PiP のツールチップ / アクセシビリティ名を簡体字中国語、日本語、英語で追加。
- 製品 / MSIX バージョンを 1.1.0 / 1.1.0.0 に更新し、専用の受け入れ契約と署名済み x64 受け入れパッケージ工程を追加。

## 確認ポイント

- 再生中に PiP へ移行しても映像 / 音声が継続し、メディアが先頭から再読み込みされないこと。
- 小窓が CompactOverlay として前面に表示され、サイズ変更できること。再生中のコントロール自動非表示とマウス再表示が機能すること。
- 外部メイン字幕 / 第2字幕が継続して表示され、小窓では適切に縮小されること。
- Escape または戻るボタンで終了した後、元のウィンドウサイズ / 最大化状態、サイドバー、通常レイアウトが復元されること。

## 対応環境

- Windows 10 2004 / Windows 11
- x64
