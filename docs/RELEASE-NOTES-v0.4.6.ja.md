# Eizo v0.4.6

## キャッシュシステム

Eizo 0.4.6 では、従来プレースホルダーだったキャッシュ画面を実際の統合キャッシュシステムへ置き換え、WebDAV 再生をブロックキャッシュのデータパスへ接続しました。

### 主な変更

- 独立した `Eizo.Cache` コンポーネントでメディア、アートワーク、メタデータ、字幕を統合管理。
- 実際のディスク使用量、カテゴリ別容量、キャッシュ項目、WebDAV セッション診断を表示。
- 8 / 16 / 32 / 64 / 128 GB の上限、LRU 自動削除、オフライン保護に対応。
- Bangumi JSON とリモート外部字幕を統合キャッシュへ移行し、旧ディレクトリも自動移行。
- WebDAV 動画を 4 MiB の Range ブロックでキャッシュし、ローカル命中時は再ダウンロードしません。
- Seek 後は対象ブロックから読み込み、1 ブロック先の先読みを実行。
- ETag / Last-Modified / Content-Length をリモートファイルのバージョン指紋として利用。
- 「リモート事前キャッシュ」設定がメディア単位の実際のキャッシュ量を制御。
- Range 対応を確認済みの WebDAV ソースでは、再生キューの次の項目もキャッシュ経由で再生。
- Range 非対応サーバーは従来の直接再生へフォールバック。
- キャッシュヒット率、メモリ/ディスクヒット、Range ダウンロード回数と通信量を表示。

## Playback 0.2.2

- ホスト提供のランダムアクセスメディアソース API を追加。
- Eizo 側で暫定適用していた並行処理・ライフサイクル修正を正式に上流化。
- DisposeAsync の重複呼び出し回帰を修正。
- Eizo は正式な Playback 0.2.2 commit を直接固定し、ローカルパッチを廃止。

## 検証

0.4.6 の受け入れテストでは、キャッシュ単体テスト、統合契約、非ゼロオフセット WebDAV Range 実行テスト、Playback Stage 7、Release x64 ビルド、MSIX の署名・インストール・起動、および独立コンポーネントのフォールバックを検証します。
