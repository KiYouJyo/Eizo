# Eizo v0.4.6

## キャッシュシステム

Eizo 0.4.6 では、キャッシュ画面を動画ダウンロード管理と統合キャッシュの実用システムへ刷新し、WebDAV 再生を Range ブロックキャッシュへ正式に接続しました。

### 主な変更

- 独立した `Eizo.Cache` コンポーネントでメディア、Bangumi データ、メタデータ、字幕を統合管理。
- キャッシュ画面を動画ダウンロード管理中心に再設計し、自動生成キャッシュは「アプリキャッシュ」として一括表示・削除可能。
- エピソード詳細から単話を直接キャッシュでき、開始直後からキャッシュ画面に表示。
- ダウンロード進捗、取得済み/総容量、平滑化した実 WebDAV ダウンロード速度（MB/s）を表示。
- ダウンロード中カードをクリックして一時停止/再開、右クリックで削除と部分ブロックの清掃が可能。
- 完了カードでは進捗表示を隠し、クリックすると WebDAV 再確認なしでローカルキャッシュから直接再生。
- 丸角カードを単一サーフェス化し、進捗更新は同じカードを更新するためジャンプしません。
- エピソード番号を保持し、旧キャッシュも Recognition から可能な限り復元。
- WebDAV 動画を 4 MiB Range ブロックでキャッシュし、既存ブロックを再利用。
- Seek 後の対象ブロック読み込みと先読みをサポート。
- ETag / Last-Modified / Content-Length をリモートメディアのバージョン指紋として利用。
- 8 / 16 / 32 / 64 / 128 GB 上限、LRU 自動削除、オフライン保護に対応。
- Bangumi JSON とリモート字幕を統合キャッシュへ移行し、旧キャッシュも自動移行。
- Range 非対応サーバーは従来の直接再生へフォールバック。

## Playback 0.2.2

- ホスト提供のランダムアクセスメディアソース API を追加。
- Eizo が暫定保持していた並行処理・ライフサイクル修正を正式に上流化。
- 重複 DisposeAsync のライフサイクル回帰を修正。
- Eizo は正式な Playback 0.2.2 commit を直接固定し、ローカルパッチを廃止。

## 検証

0.4.6 の受け入れテストでは、キャッシュ単体テスト、ダウンロード管理契約、非ゼロオフセット WebDAV Range 実行テスト、Playback Stage 7、Release x64 ビルド、署名済み MSIX のインストール/起動、one-click パッケージ、独立コンポーネントのフォールバックを検証します。
