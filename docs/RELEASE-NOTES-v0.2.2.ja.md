# Eizo v0.2.2 — アップデーター修正と中幅ナビゲーション改善

このリリースは、v0.2.1 以降に確認された更新処理とレスポンシブ UI の問題を修正し、アプリ内更新経路の回帰テストを行うためのバージョンです。

- GitHub Release のダウンロード完了後、WinVerifyTrust が MSIXBundle のファイルハンドルを保持したまま署名を再読込し、`BundleDownloadFailed` と誤表示される可能性があった問題を修正しました。
- WinTrust の状態を先に CLOSE してファイルハンドルを解放した後で `AppxSignature.p7x` を読み込む順序へ変更しました。正式 Release CI では Eizo 自身の `MsixBundleSignatureVerifier` で最終署名バンドルを検証します。
- ダウンロード失敗、署名読込失敗、更新一時保存失敗を別々のエラーとして扱うようにしました。
- 小さいウィンドウではプレイヤー下部の操作ボタンをレスポンシブ Grid に切り替え、必要に応じて中央の再生操作を 2 行目へ移動して重なりを防ぎます。
- 中/小幅 NavigationView の Pane 色判定を `ShellNavigation.ActualTheme` に統一し、ライトテーマで展開後に折りたたむと黒くなる問題を修正しました。
- 中幅の「カテゴリ」子メニューは WinUI 標準 Flyout に戻し、独自 Mica 上書きを削除しました。
- カテゴリタブと左ナビゲーションのアイコンを同一の `Symbol.Library` ソースへ統一しました。
- 「プロジェクトとオープンソース」カードから GitHub、Releases、プライバシー説明を実際に開けるようにしました。
- v0.2.1 の全画面、サイドバー、音量、ライフサイクル、ライトテーマ修正を引き続き含みます。

> v0.2.1 からアプリ内更新で v0.2.2 へアップグレードし、今回のアップデーター修正を確認することを推奨します。
