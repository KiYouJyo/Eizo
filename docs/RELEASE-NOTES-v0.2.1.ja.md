# Eizo v0.2.1 — プレイヤー体験・Eizo.Playback 統合・安定性修正

- Eizo.Playback 再生レイヤーを正式に統合しました。Eizo UI は LibVLCSharp 型から分離したまま、固定バージョンと固定コミットからローカル NuGet パッケージを復元し、再現可能なビルドを維持します。
- プレイヤーページを大幅に再構築し、実メディア再生、再生/一時停止、シーク、チャプター、字幕・音声トラック、再生速度、音量、全画面操作を統合しました。
- 音量ボタンとスライダーを追加し、全画面ではマウスホイールで 5% 単位の音量調整に対応しました。
- 全画面コントロールの自動非表示を修正し、マウス移動や操作で再表示するようにしました。
- 右側の再生キュー/字幕・音声パネルを整理し、全画面では Overlay + 外側クリックで閉じ、通常表示では Inline の常駐挙動を維持します。
- ライトテーマでも全画面中のプレイヤー UI はダークテーマに統一し、全画面終了後は元のライトテーマへ戻ります。
- 通常ライトテーマで発生していたサイドバー背景と中央ステータス表示のテーマ不整合を修正しました。
- 全画面終了と動画タブ終了のライフサイクルを再設計し、Playback Surface / LibVLC / D3D リソースを先に解放してからビジュアルツリーを外すことで、フリーズの発生確率を低減しました。
- 再生状態の保持とカテゴリーページ内容を改善し、タブ切り替え後もメディア文脈と再生位置を維持します。
- About ページから Eizo.Playback の独立更新カードを削除しました。Eizo.Playback は独立開発リポジトリのまま、Eizo 側で固定統合します。
- x64 GitHub 配布契約として、署名済み MSIXBundle、one-click パッケージ、SHA256SUMS.txt を継続します。
