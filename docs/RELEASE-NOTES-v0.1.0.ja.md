# Eizo v0.1.0 WinUI 3 UI 基盤版

- Eizo 初のインストール可能な WinUI 3 基盤版として、タイトルバー、NavigationView、Mica 背景、ネイティブカード体系、レスポンシブなページ構成を実装しました。
- SpatialViewer と同じマルチタブの考え方を導入しました。「+」でホーム型タブを追加し、ハンバーガーメニューは現在のホーム型タブだけを切り替え、個別作品の詳細を開いた時だけ独立したコンテンツタブを作成します。
- ホーム、アニメ、映画、ドラマ、メディアソース、キャッシュ、情報、設定など v0.1 の主要画面を実装し、見出し・検索欄・Hero カード・横方向のネイティブ選択 UI の間隔と構成を統一しました。
- 简体中文、日本語、English の3言語リソースと、日本メディアを優先したタイトル表示設定を導入しました。3言語のリソースキー一致は CI で継続検証します。
- SpatialViewer のテーマ方式を再利用し、システム追従・ライト・ダークを即時切り替え可能にしました。タイトルバー、ナビゲーション、タブ、Mica、ComboBox ポップアップも同じテーマに同期します。
- x64 自己署名 MSIXBundle、軽量 one-click インストーラーブートストラップ、SHA-256 チェックサムを提供します。ブートストラップには公開証明書と検証・ダウンロードスクリプトだけを含み、秘密鍵や Windows App Runtime は含みません。
- v0.1.0 は UI Foundation とアプリシェルを主目的とする版です。実際のメタデータ取得、リモートメディアソース、再生エンジン、完全なライブラリデータフローは今後の版で順次接続します。
