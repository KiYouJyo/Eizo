# Eizo v0.2.0 稳定性、三语与应用内更新

- 修复深色模式偶发显示异常，统一窗口根节点的主题归属，并继续保持跟随系统、浅色与深色模式即时切换。
- 重构窗口极限缩放下的响应式布局，移除主页与分类页中不稳定的自动网格路径，恢复与 SpatialViewer 一致的标签页自适应逻辑；已通过极小窗口与连续快速缩放回归测试。
- 接入完整的简体中文、日本語、English 运行时切换，并支持“跟随系统”；切换后会刷新已缓存页面与标签文本。
- 接入 GitHub Releases 应用内更新：检查版本、下载、SHA-256 校验、MSIX 签名验证、安装与重启均在应用内完成；更新按钮按当前状态切换，不再常驻独立重启按钮。
- 按 UrbanPlanToolbox 的实现接入单实例启动。应用已打开时再次点击图标会激活既有窗口，不再创建第二个窗口或第二个应用实例。
- 记录最后一次正常窗口尺寸与最大化状态。应用关闭后再次启动会恢复上次的可用窗口大小，并对当前显示器工作区进行安全裁剪。
- 保持 x64 GitHub 发行合同：签名 MSIXBundle、轻量 one-click 安装包与 SHA256SUMS.txt。
- v0.2.0 继续聚焦应用壳层、稳定性与基础设施；媒体刮削、媒体源与 Eizo.Playback 播放适配层将在后续版本继续接入。
