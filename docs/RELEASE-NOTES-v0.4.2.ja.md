# Eizo v0.4.2

## Bangumi 公開コンテンツ連携

- Bangumi のネットワークデータをローカルの `Eizo.Metadata` と分離する独立 `Eizo.Bangumi` データ層を追加しました。
- 「放送カレンダー / 新番 / ランキングと発見」を実データへ接続し、「追番」はアカウント連携を行う後続バージョンまでプレースホルダーとして維持します。
- 新番ページは四半期を構成する3か月分のTVアニメを取得・重複排除し、前クール / 次クール / 今期へ戻る操作に対応します。
- ランキングは総合、今期、今年の3スコープに対応し、総合と今年は次ページの追加読み込みが可能です。
- 放送カレンダーは公開 `/calendar` API を利用し、初期表示を今日の曜日に合わせます。
- 作品カードから Eizo 内の Bangumi 詳細ページを開き、ポスター、タイトル、放送開始日、話数、評価、順位、收藏数、概要、タグを確認でき、Bangumi 本体へ移動できます。
- ホームの「今期」欄はハードコード例を廃止し、現在の Bangumi 四半期データを表示します。「すべて表示」から新番ページへ移動できます。
- 日程30分、ランキング2時間、四半期6時間、詳細24時間のローカルキャッシュを導入し、通信失敗時は既存の古いキャッシュへフォールバックします。
- Bangumi の要件に沿った Eizo 0.4.2 User-Agent を送信し、公開 API の1ページ50件上限を守ります。
- Bangumi JSON/parser の単体テスト、公開連携契約、実ネットワーク API smoke workflow を追加しました。
- アカウントログイン、收藏書き込み、視聴進捗同期、Bangumi Subject とローカルライブラリの自動紐付けは本バージョンには含めません。

Eizo 0.4.1 のライブラリ分類ページ、外部 Metadata runtime、および Eizo 0.4.0 の再生キュー / 外部字幕 / デュアル字幕も回帰検証します。
