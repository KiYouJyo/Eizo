# Eizo v0.3.2 プレイヤー安定性・操作修正

Eizo v0.3.2 では、プレイヤーの並行処理、ライフサイクル、高頻度操作時の安定性を重点的に改善し、全画面表示とショートカット操作も調整しました。WebDAV 再生時の読み込みカード表示問題については、本リリースでは追加修正を行わず、既知の問題として次回以降に持ち越します。

## プレイヤー安定性

- メディアを開く処理、字幕切替、シーク、再生状態コールバックが競合した際のハングや状態不整合を抑えるため、再生操作の直列化を再設計しました。
- 再生セッションのキャンセルとライフサイクル保護を追加し、ページのアンロードやエンジン解放後に古い処理が置き換え済みの再生インスタンスへアクセスしないようにしました。
- プレイヤーサーフェスの初期化、解放、再アタッチ時の競合を修正し、タブ切替やページライフサイクル変化によるハングを抑制しました。
- Eizo.Playback に不足していた `PlaybackOperationQueue` と診断トレース基盤を補完し、新規環境での依存関係復元時の誤判定も修正しました。
- 並行処理の回帰テストを追加し、.NET 10 の Microsoft Testing Platform 方式へ移行しました。

## 字幕・再生操作

- 字幕トラックを連続切替した際、ComboBox のデータ再構築が原因で発生する WinUI クラッシュのリスクを修正しました。
- 字幕・音声トラックなどの選択では最新のユーザー操作を優先し、古い待機操作をキャンセルするようにしました。
- ウィンドウレベルでスペースキーによる再生 / 一時停止に対応しました。
- 全画面表示中は ESC で終了できるようにし、全画面切替時の状態分離も強化しました。
- 再生位置 UI の高頻度更新をまとめ、メインスレッド負荷を軽減しました。

## ビルド・リリース

- Eizo.Playback の固定依存パッチについて、新規 `--no-checkout` ワークツリーでの復元処理を修正しました。
- Release x64、並行処理テスト、MSIX ビルド、署名フローを検証済みです。
- 正式リリースでは引き続き、署名済み x64 MSIXBundle、one-click インストーラー、SHA256SUMS.txt を提供します。

## 既知の問題

- **WebDAV 動画の再生開始時に、読み込み状態カードが表示されない場合があります。** 本バージョンではこの UI 問題の追加修正をいったん見送りました。動画再生自体はこのカード表示を成功条件としていません。今後、読み込み状態モデルを別途整理します。
