# Eizo 0.5.12 — 真实内容 UI 收口

0.5.12 继续沿用已经确定的界面框架，把 0.5.9–0.5.11 已接通的真实媒体内容整理成稳定的用户界面状态，不新增 AniList，也不重做页面结构。

## 本版完成

- 媒体库卡片不再显示识别置信度和来源路径/文件信息等开发期内容。
- 单作品右键菜单保留“重新刮削 / 手动匹配 / 清除手动匹配”，移除正常用户菜单中的识别/元数据调试入口。
- 媒体库中的单作品元数据操作增加进行中、成功、警告和失败状态反馈。
- 详情页缺失的原始标题、年份、元信息和简介会直接隐藏，不再显示重复标题或 “-” 占位符。
- 详情页增加单作品重新刮削/手动匹配状态反馈。
- 当前季没有真实可播放条目时显示明确空状态。
- 旧的 title-only 详情入口不再展示示例季、示例集数或 Sample 来源。
- 首页独立/未聚合作品不会再跳进旧的样例详情页；仍可直接播放真实媒体文件。

## 边界

- 本版是 UI 收口，不重新设计媒体库/详情页大框架。
- AniList 继续跳过。
- 识别报告导出仍保留，用于诊断；诊断字段不再侵入普通卡片与详情展示。
