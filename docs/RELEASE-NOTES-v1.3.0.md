# Eizo v1.3.0

## 原生动漫搜索与索引库

Eizo 1.3 移除 Bangumi 下原有的“动画日志”独立页面，将该入口重构为原生 WinUI 3“动漫搜索”。页面直接使用 Bangumi 动画索引数据，不嵌入网页，并延续 Eizo 1.2 的统一卡片体系。

## 本版完成

- 删除“动画日志”页面及其导航、工作区路由与专用 UI。
- 新增“动漫搜索”页面，提供原生 WinUI 3 `AutoSuggestBox` 搜索框。
- 新增分类、来源、类型、地区、受众、年份六组原生 `RadioButtons` 筛选。
- 新增排名、热度、评分、匹配度排序。
- Bangumi 搜索扩展到 `meta_tags`、`tag`、`air_date` 等索引条件，并限定动画类型与非 NSFW 条目。
- 搜索结果复用 `MediaPosterCard`、统一海报尺寸、悬停与键盘焦点样式。
- 默认列表沿用带缓存的 Bangumi 综合排名；主动搜索与筛选直接请求 Bangumi 动画索引。
- 条目点击继续进入现有 Eizo Bangumi 详情页，并保留收藏、评论、关联条目等后续流程。
- 默认卡片优先显示原文标题，中文名作为辅助标题。
- 新增 v1.3 动漫索引回归契约及 Bangumi 高级搜索单元测试。
- 将“排行与发现”移动到“动漫搜索”正下方，并换用独立的发现/星标图标，避免与搜索图标重复。
- 动漫搜索的六组筛选从右侧栏改为结果区上方的横向分组筛选，更接近内容站点常见的分类索引模式。
- 移除“加载更多”按钮；列表滑到底部时自动继续加载下一批 50 个条目。
- 新番页面的季度长条改为可点击的原生 WinUI 3 季度选择器，可在弹出的年度/季度面板中快速跳转到指定年份和冬/春/夏/秋季。
- 动漫搜索改为整页统一纵向滚动，筛选区域支持原生展开/收起，不再固定占据上方高度；搜索、重置筛选、排序三个操作统一右对齐。
- 从主页“继续观看”进入播放器时会先还原所属作品，播放队列与正常从作品详情进入时保持一致，不再只出现当前一集。
- 播放队列的当前项/选中高光增加圆角，与侧栏整体卡片视觉一致。
- 全屏播放器新增方向上/下键以 5% 步进调节音量；方向键和鼠标滚轮调音量时均仅在顶部居中显示半透明音量横幅，不再拉起底部控制区。
- 播放文件存在内封字幕时，第一字幕选择器只保留内封字幕；第一字幕的位置与背景控制保持灰色不可调节，并提示“本视频包含内封字幕，该样式不可调整”；外挂字幕统一在第二字幕区选择。
- 全屏长按左右方向键临时变速不再拉起底部控制栏，改为顶部居中的半透明倍速横幅。
- 全屏与非全屏状态下，点击视频画面均可切换播放 / 暂停。
- 产品 / MSIX 版本提升为 1.3.0 / 1.3.0.0。

## 验收重点

- Bangumi 导航中不再出现“动画日志”，对应入口显示“动漫搜索”。
- 页面不得包含 WebView/WebView2 或网页嵌入组件。
- 搜索框、排序、六组顶部横向筛选、海报结果与自动分页均为原生 WinUI 3 组件。
- 筛选组合应映射为 Bangumi subject search 的动画类型、标签与年份条件。
- 点击搜索结果应正常进入既有 Bangumi 条目详情页。

## 兼容性

- Windows 10 2004 / Windows 11
- x64
