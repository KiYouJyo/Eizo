# Eizo v0.3.0 — WebDAV 媒体来源与远程播放

v0.3.0 将 Eizo 从本地播放器基础架构推进到可实际使用的远程媒体播放阶段，首个重点媒体来源为 WebDAV。

## WebDAV 媒体来源

- 新增独立的媒体来源 Provider 架构，并将本地来源与 WebDAV 来源分离注册，为后续更多网盘与远程来源保留扩展接口。
- 支持添加、保存和管理 WebDAV 媒体来源；认证信息通过 Windows PasswordVault 保存，并通过独立凭据接口与 Provider 解耦。
- 支持经过认证的 WebDAV PROPFIND 扫描、目录解析与远程媒体发现，并补充 401、404、Range 请求等运行时回归测试。
- 修正 WebDAV 返回绝对路径 href 时的 URL 解析，确保其正确绑定到当前 HTTP(S) origin。
- 未刮削目录中的远程视频会显示真实文件扩展名，方便识别资源格式。

## 远程播放

- Eizo.Playback 更新到 0.2.1，并接入带认证信息的网络媒体打开路径。
- WebDAV 中识别到的视频现在可以直接进入 Eizo 播放器播放。
- 已验证远程视频播放、进度拖动（Seek）与倍速播放。
- 网络播放链路支持 HTTP Range 请求，并覆盖认证失败与资源不存在等错误路径。

## 播放器与媒体来源 UI

- 媒体来源列表改为完整卡片式视觉，不再只是单行文字。
- 加载状态改为 Mica surface + WinUI 原生 ProgressRing，并显示加载进度与实时下载速度。
- 修正倍速滑块标识与实际进度位置不一致的问题。
- 删除侧栏底部重复的播放信息。
- 删除底部控制区重复的音轨与字幕切换，将两者统一收拢到右侧“字幕与音轨”区域。
- 删除播放器内的“打开本地视频”入口，让播放器只承接已选媒体的播放上下文。
- 补充播放器 UI 清理契约测试与 CI 守卫，避免重复控件和加载反馈回退。

## 版本与发布

- 面向用户的版本号保持为 **v0.3.0**。
- Windows 包版本为 **0.3.0.1**；最后一位是本次 WebDAV 鉴权与播放修正后的包修订号。
- GitHub Release 继续提供三项正式资产：签名 x64 MSIXBundle、one-click 安装包与 SHA256SUMS.txt。
