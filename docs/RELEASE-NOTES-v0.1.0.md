# Eizo v0.1.0 WinUI 3 UI 基础版本

- 完成 Eizo 首个可安装的 WinUI 3 应用基础版本，建立标题栏、NavigationView、Mica 背景、原生卡片体系与响应式页面框架。
- 建立与图览一致的多标签工作流：保留“+”新建主页型标签，汉堡菜单只切换当前主页标签内容，打开具体作品详情时才创建独立内容标签。
- 落地主页、动漫、电影、电视剧、媒体来源、缓存、关于与设置等 v0.1 核心界面，并统一标题、搜索框、Hero 卡片和横向原生选择控件的布局节奏。
- 接入简体中文、日本語、English 三语资源与日本媒体优先的标题显示设置；三语资源键由 CI 持续校验一致性。
- 复用 SpatialViewer 的主题机制，支持跟随系统、浅色与深色模式即时切换，并统一标题栏、导航、标签页、Mica 与 ComboBox 浮层的主题表现。
- 提供 x64 自签名 MSIXBundle、轻量 one-click 安装引导包与 SHA-256 校验清单；安装引导仅包含公开证书和校验/下载脚本，不包含私钥或 Windows App Runtime。
- v0.1.0 重点是 UI Foundation 与应用壳层；真实媒体刮削、远程媒体源、播放器内核和完整媒体库数据链将在后续版本继续接入。
