# Eizo v0.4.5

Bangumi の作品詳細を、コミュニティ内容まで Eizo 内で閲覧できるデスクトップ入口へ拡張しました。本リリースは読み取り専用で、ローカルライブラリのスクレイピング経路や Bangumi への書き込みは変更しません。

- `BangumiCommunityClient` / `BangumiCommunityRepository` を追加し、Private API `/p1` を安定版 Public API `/v0` から分離しました。
- 作品詳細に「短評」「長評」「ディスカッション」「関連」のタブを追加しました。
- 短評ではユーザー、視聴状態、評価、更新時刻、reaction 数を表示し、ページングと「見たい / 見た / 見てる / 積み / 切った」フィルターに対応しました。
- 長評を Eizo 内で全文表示し、作者、タグ、閲覧数、返信数、コメント、一段階のネスト返信を表示します。
- 作品ディスカッションを Eizo 内で開き、主投稿、返信、一段階のネスト返信を表示します。
- おすすめ作品・関連作品は Eizo 内の Bangumi 詳細タブへ遷移できます。
- コミュニティ BBCode は安全なプレーンテキストとして表示し、「Bangumi で開く」も fallback として残しています。
- ログイン済みの場合は 0.4.4 の OAuth 資格情報を任意の Bearer として再利用し、未ログインでも公開コミュニティ内容を閲覧できます。
- Private API の一部が失敗しても既存の作品基本情報は維持されます。
- 中国語・日本語・英語の UI、parser/client テスト、統合 contract、実 API smoke を追加しました。

短評投稿、トピック作成、返信、いいね、再生進捗の書き戻しは本版には含めず、後続バージョンで個別に扱います。
