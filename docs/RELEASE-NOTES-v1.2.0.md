# Eizo v1.2.0

## 统一卡片设计与缓存管理

Eizo 1.2 对媒体卡片进行一次结构性收口：媒体库与“我的追番”不再各自维护相似的卡片 XAML，而是共享统一的卡片组件、尺寸与交互状态。同时补全视频缓存卡片的右键操作。

## 本版完成

- 新增共享卡片设计资源，统一海报卡片的尺寸、圆角、边框、悬停、按压、键盘焦点与文字层级。
- 新增可复用的 `MediaPosterCard`，媒体库与 Bangumi“我的追番”使用同一个海报卡片组件。
- 修复“我的追番”卡片高光范围与卡片本体不一致的问题；交互高光现在与卡片边界和圆角完全一致。
- 媒体库继续隐藏来源诊断信息；“我的追番”则通过同一组件的可选底部信息行显示收藏进度。
- 视频缓存列表改用共享横向卡片样式，右键作用于整张卡片，而不是仅作用于内部文字区域。
- 视频缓存右键菜单新增“打开文件目录”和“删除缓存”。
- “打开文件目录”优先打开该视频缓存块所在目录；对尚未生成完整缓存组的下载任务，回退到 Eizo 缓存根目录。
- “删除缓存”为直接操作，不增加确认弹窗；删除项继续使用危险操作视觉样式。
- 新增 v1.2 卡片 UI 回归契约，并把相关检查接入仓库验证流程。
- 产品 / MSIX 版本提升为 1.2.0 / 1.2.0.0。

## 验收重点

- 媒体库与“我的追番”的同尺寸卡片应保持完全一致的外框、圆角和交互反馈。
- “我的追番”悬停高光不得超出或缩小于实际卡片。
- 缓存卡片任意位置右键都应出现“打开文件目录 / 删除缓存”。
- 删除操作应直接执行，不出现二次确认弹窗。
- 深色 / 浅色主题和键盘焦点状态下，卡片仍应保持统一视觉边界。

## 兼容性

- Windows 10 2004 / Windows 11
- x64
