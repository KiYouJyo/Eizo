# Eizo v1.1.0

## 原生画中画与播放体验完善

Eizo 1.1 为播放器加入基于 Windows App SDK CompactOverlay 的原生画中画，并在不重新创建播放内核的前提下保持当前播放会话。

## 本版完成

- 在播放器标题栏右侧增加画中画入口，使用 WinUI 原生 Button 与 Segoe Fluent MiniExpand 图标。
- 进入画中画时复用当前 PlaybackView，不卸载或重建 LibVLC 播放引擎，因此不会因切换窗口模式重新打开媒体。
- 画中画与全屏互斥；进入小窗后隐藏应用标题栏、导航和播放器侧栏，仅保留高频播放控制。
- 保留后退 10 秒、播放/暂停、前进 10 秒与返回普通窗口；按钮继续使用 WinUI 原生模板、焦点、悬停与按压反馈。
- 播放时自动隐藏画中画控制区；鼠标移动后重新显示，指针停留在控制区时保持显示。
- 支持 Escape 退出画中画，并支持在画中画窗口内使用鼠标滚轮调节音量。
- 针对小窗缩小外挂字幕字号与内边距，退出后恢复用户原有字幕与播放器布局。
- 记录进入画中画前的窗口位置、尺寸和最大化状态，退出后恢复；若 Windows 从外部结束 CompactOverlay，也会同步恢复 Eizo 的界面状态。
- 画中画入口和退出提示完成简体中文、日本語、English 三语本地化与 AutomationProperties 无障碍名称。
- 产品 / MSIX 版本提升为 1.1.0 / 1.1.0.0，并新增专用验收契约与签名 x64 验收包流程。

## 验收重点

- 播放中进入画中画，画面与声音应连续，不应重新从头加载媒体。
- 小窗应保持置顶 CompactOverlay 行为，可调整大小；控制区在播放时自动隐藏并可由鼠标唤回。
- 外挂主字幕 / 第二字幕应继续显示，且小窗字号更紧凑。
- Escape 或返回窗口按钮退出后，应恢复原窗口尺寸 / 最大化状态、侧栏状态和正常播放器布局。

## 兼容性

- Windows 10 2004 / Windows 11
- x64
