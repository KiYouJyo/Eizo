# Eizo v0.4.6

## 缓存系统

Eizo 0.4.6 将原先的缓存占位页面落地为真实的统一缓存系统，并把 WebDAV 媒体播放正式接入分块缓存数据面。

### 主要更新

- 新增独立的 `Eizo.Cache` 组件，统一管理媒体、封面、元数据与字幕缓存。
- 缓存页显示真实磁盘占用、分类容量、缓存项目与会话级 WebDAV 缓存诊断。
- 支持 8 / 16 / 32 / 64 / 128 GB 容量上限、LRU 自动清理和离线内容保护。
- Bangumi JSON 与远程外挂字幕迁入统一缓存，并兼容旧目录自动迁移。
- WebDAV 视频使用 4 MiB Range 分块缓存；命中本地块时不再重复下载。
- 支持 Seek 后按目标块读取，并加入单块前瞻预取。
- ETag / Last-Modified / Content-Length 用于远端媒体版本指纹，避免旧缓存误命中。
- “远程预缓存”设置现在真实限制单媒体缓存工作集。
- 同一 WebDAV 源在完成 Range 能力验证后，播放队列后续项目也会复用缓存读取链。
- 不支持 Range 的服务器继续使用原有直连播放作为兼容回退。
- 缓存诊断显示缓存命中率、内存命中、磁盘命中以及 Range 下载次数与流量。

## Playback 0.2.2

- 新增宿主随机访问媒体源接口，允许 Eizo 将 WebDAV 与缓存策略留在应用层。
- 原先由 Eizo 临时携带的播放器并发与生命周期补丁已经正式上游。
- 修复重复 DisposeAsync 的生命周期回归。
- Eizo 现在直接固定到正式 Playback 0.2.2 commit，不再应用本地源码补丁。
