# Eizo v0.4.6

## 缓存系统

Eizo 0.4.6 将缓存页从占位界面升级为完整的视频下载与统一缓存系统，并把 WebDAV 播放正式接入 Range 分块缓存数据面。

### 主要更新

- 新增独立的 `Eizo.Cache` 组件，统一管理媒体、Bangumi 数据、元数据与字幕缓存。
- 缓存页重新定位为视频下载管理页；应用自动产生的缓存统一汇总为“应用缓存”，支持一键清理。
- 剧集详情页可直接缓存单集视频；下载任务会立即显示在缓存页。
- 下载卡片实时显示进度、已下载/总大小与平滑后的真实 WebDAV 下载速度（MB/s）。
- 点击下载中的卡片可暂停，再次点击继续；右键可删除并清理下载中的分块。
- 已完成卡片隐藏进度区域，点击即可直接从本地缓存分块播放；完成视频不依赖 WebDAV 在线探测。
- 视频缓存卡片使用稳定的圆角卡片模板，进度更新原位刷新，不再重建列表或跳动。
- 缓存卡片保留剧集编号；旧缓存可通过媒体库 Recognition 回查并恢复集数。
- WebDAV 视频使用 4 MiB Range 分块缓存；已有本地块会复用，不重复下载。
- 支持 Seek 后按目标块读取，并加入前瞻预取。
- ETag / Last-Modified / Content-Length 用作远端媒体版本指纹，避免旧缓存误命中。
- 支持 8 / 16 / 32 / 64 / 128 GB 容量上限、LRU 自动清理和离线内容保护。
- Bangumi JSON 与远程外挂字幕迁入统一缓存，并兼容旧目录自动迁移。
- 不支持 Range 的服务器继续使用原有直连播放作为兼容回退。

## Playback 0.2.2

- 新增宿主随机访问媒体源接口，让 WebDAV 凭据与缓存策略继续保留在 Eizo 应用层。
- 原先由 Eizo 临时携带的播放器并发与生命周期补丁已经正式上游。
- 修复重复 DisposeAsync 的生命周期回归。
- Eizo 直接固定到正式 Playback 0.2.2 commit，不再应用本地源码补丁。
