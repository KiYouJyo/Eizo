# Eizo v0.4.0

## 再生キュー、外部字幕、デュアル字幕

- 実際のメディアライブラリ集約結果を再生キューへ接続し、キュー選択による実メディア切替と再生終了後の自動連続再生に対応しました。
- チャプターがない動画では前 / 次ボタンを前話 / 次話として使用します。
- ローカルおよび WebDAV の同一フォルダーにある外部字幕を自動検出し、SRT / VTT / ASS / SSA をサポートします。
- 外部の第1字幕と第2字幕を Eizo の WinUI オーバーレイ描画へ統一し、ASS / SSA ファイル内の古いフォントスタイルに依存しない表示へ変更しました。
- 第1字幕と第2字幕はそれぞれ垂直位置と背景不透明度を独立調整でき、4つの表示設定は話数切替、キュー切替、アプリ再起動後も保持されます。
- 字幕オーバーレイをプレイヤー幅に近い横長レイアウトへ変更し、可能な限り1行表示し、必要な場合のみ折り返します。
- スペシャル / OVA の集約と再生ソース選択を修正し、明示的な OVA / OAD / ONA / SP / SPECIAL は通常話と同じ番号でも統合されません。古い Recognition スナップショットもファイル名を基準に補正します。
- スペシャルのタイトルが通常シーズンの Metadata に汚染される問題を修正しました。
- About の「個別更新可能なコンポーネント」から Playback / 再生コア行を削除し、Metadata ランタイムの更新入口のみを表示します。Playback runtime と bundled fallback の構成自体は維持します。
- Eizo.Metadata v0.2.20 を継続利用し、外部 Metadata runtime のバージョン、SHA-256、互換性、pending → restart → active、失敗時フォールバックを維持します。

本バージョンは Release ビルド、Windows x64 MSIXBundle 署名、実インストール / 起動、プレイヤー / 字幕契約、Stage 7 Playback Integration、Metadata bundled fallback を検証済みです。
