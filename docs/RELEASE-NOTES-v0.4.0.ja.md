# Eizo v0.4.0

## プレイヤー機能強化・受け入れテスト版

- 実際のメディアライブラリ集約結果を再生キューへ接続しました。
- キュー選択による実メディア切替と、再生終了後の自動連続再生に対応しました。
- チャプターがない動画では前/次ボタンを前話/次話として使用します。
- ローカルおよび WebDAV の同一フォルダーにある外部字幕を自動検出します。
- SRT / VTT / ASS / SSA をサポートします。
- 主字幕は Eizo.Playback / LibVLC を継続利用し、独立した第2字幕レイヤーを追加しました。
- 第2字幕は再生位置、シーク、エピソード切替に同期します。
- Playback、Recognition/Metadata の独立更新コンポーネントと bundled fallback 構成を維持します。

このパッケージは Eizo 0.4.0 プレイヤー機能の実機受け入れテスト用です。
