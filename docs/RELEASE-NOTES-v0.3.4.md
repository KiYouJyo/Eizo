# Eizo v0.3.4

## WebDAV 大目录扫描稳定性与进度持久化

- 修复大型 WebDAV 媒体目录在长时间扫描过程中容易因 SSL/TLS 或瞬时网络错误而失败的问题。
- 同一 WebDAV 来源的目录扫描现在复用 HTTP/TLS 连接，减少对子目录逐级扫描时的重复连接与握手开销。
- 对瞬时 SSL/网络异常、超时、HTTP 408、429 与 5xx 响应加入有限退避重试，并将单目录请求超时提高到 90 秒。
- 扫描任务提升为应用级状态，不再依赖“媒体来源”页面实例；切换到其他页面后扫描继续进行，返回页面仍可看到当前进度。
- 来源卡片实时显示已处理/已发现目录与视频数量；已知目录总数会随着新子目录被发现动态增长。
- 扫描过程中禁止编辑或删除对应媒体来源，避免凭据、目录范围和扫描状态发生竞争。
- 扫描失败时保留上一次成功建立的媒体目录，只有完整扫描成功后才替换当前来源的媒体条目。
- 已通过 WebDAV runtime probe、来源管理契约、Recognition 集成、WinUI 3 编译以及 Stage 7 播放集成与 MSIX/LibVLC 检查。
