# Eizo v1.2.1

## 手动视频缓存单文件化

Eizo 1.2.1 只调整“手动缓存视频”这一条路径。主动点击缓存后，完整视频不再以大量 4 MB `.blk` 文件保存，而是按原始容器扩展名保存为一个完整媒体文件；播放过程产生的自动预缓存 / 随机访问缓存仍继续使用原有分块机制。

## 本版完成

- 手动缓存使用独立的 `manual-video:` 缓存组，与自动播放缓存彻底分离。
- 下载过程仍按 WebDAV Range 分段获取数据，以保留暂停 / 恢复、进度和速度统计，但分段只顺序写入一个临时文件，不再逐段写入缓存目录。
- 下载完成后一次性提交为单个媒体文件，并保留源文件扩展名，例如 `.mkv`、`.mp4`、`.webm`。
- 如果自动播放缓存中已经存在对应分块，手动缓存可复用这些数据，避免重复网络下载；复用不会把手动缓存重新变成分块文件。
- 手动缓存完成后直接从本地完整文件播放；旧版已存在的分块离线缓存仍保留兼容播放能力。
- 缓存总量、自动清理保护、右键打开目录和删除缓存继续使用统一缓存索引。
- 旧版已经生成的 `.blk` 手动缓存不会在升级时强制重写，避免启动时对大文件进行高开销复制；删除旧缓存并重新缓存后即会生成单个视频文件。
- 自动播放预缓存逻辑没有改动，仍使用小块缓存以支持随机访问和工作集回收。

## 验收重点

- 新建一个手动缓存后，`Cache\media` 中该视频对应的持久缓存应只有一个媒体文件，而不是数百个 `.blk`。
- 媒体文件扩展名应与 WebDAV 源文件一致。
- 缓存完成后断网仍可从该单文件播放。
- 删除手动缓存后，该完整媒体文件应被删除。
- 普通 WebDAV 在线播放仍可继续生成 / 使用原有 `.blk` 自动缓存。

## 兼容性

- Windows 10 2004 / Windows 11
- x64
