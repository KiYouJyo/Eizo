# Eizo v0.3.4

## WebDAV 大規模スキャンの安定性と進捗保持

- 大規模な WebDAV メディアディレクトリを長時間スキャンした際、SSL/TLS または一時的なネットワーク障害で失敗しやすい問題を修正しました。
- 同一 WebDAV ソースのディレクトリ列挙で HTTP/TLS 接続を再利用し、サブディレクトリごとの再接続・再ハンドシェイクを削減しました。
- 一時的な SSL/ネットワークエラー、タイムアウト、HTTP 408、429、5xx に対して有限回のバックオフ再試行を追加し、1 ディレクトリあたりのタイムアウトを 90 秒に延長しました。
- スキャン状態をページローカルからアプリケーションレベルへ移し、他ページへ移動してもスキャンを継続し、戻った際に進捗を再表示できます。
- メディアソースカードに処理済み/検出済みディレクトリ数と動画数をリアルタイム表示します。既知の総ディレクトリ数は新しいサブディレクトリの発見に応じて増加します。
- スキャン中は対象ソースの編集・削除を無効化し、認証情報やスキャン範囲との競合を防ぎます。
- スキャン失敗時には前回成功したカタログを保持し、全スキャンが正常完了した場合のみ媒体項目を置き換えます。
- WebDAV runtime probe、ソース管理契約、Recognition 統合、WinUI 3 ビルド、Stage 7 再生統合および MSIX/LibVLC 検証を通過しています。
