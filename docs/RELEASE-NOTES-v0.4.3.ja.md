# Eizo v0.4.3

## Bangumi アカウントと「追番」

- サーバーレス方式の Bangumi アカウント接続を追加しました。Bangumi 公式 Access Token ページで Token を生成し、Eizo に貼り付けて接続します。
- Access Token は Windows Credential Locker のみに保存し、`settings.json`、診断レポート、ログには書き込みません。
- 接続前に `/v0/me` で Token を検証し、現在の Bangumi ユーザー情報を取得します。
- Bangumi 親メニュー「追番」を実アカウントページへ切り替え、アニメ收藏の `見てる (type=3)` を読み込みます。
- 追番ページでは Bangumi アバター、ニックネーム、ユーザー名、ポスター、タイトル、放送日、評価、順位、視聴話数、ユーザー評価を表示します。
- ページングによる追加読み込み、更新、接続解除、既存 Bangumi 詳細ページへの遷移に対応します。
- 設定に Bangumi アカウントカードを追加し、公式 Token ページを開く、接続する、現在の接続ユーザーを確認する、安全に接続解除する操作をまとめました。
- 401 で Token 無効が確認された場合のみローカル接続状態を消去し、通常のネットワーク障害では保存済み Token を保持します。
- アカウントと收藏データは公開 Bangumi キャッシュへ保存せず、現在のバージョンではアカウント API から直接取得します。
- ユーザー / 收藏 JSON 解析、Bearer Header と「見てる」フィルタの mock テスト、Credential Locker / 追番の静的契約を追加しました。

本バージョンのアカウント連携は読み取り専用です。Bangumi 收藏状態、評価、エピソード視聴進捗は変更しません。
