# Eizo v0.6.0

## 播放器与详情体验完善

0.6.0 集中收口播放器交互、作品详情页首屏布局与更新管理体验，并将帧预览能力正式接入 Playback 运行时。

## 本版完成

- 作品详情页 Hero 改为与主页一致的横向双栏布局：左侧信息与操作，右侧保留横向 Backdrop 大图。
- Hero 高度固定收紧，减少首屏占用，让剧集、角色与制作人员信息更快进入可视区域。
- 重新刮削、手动匹配直接展示，不再收纳于更多菜单。
- 播放设置新增全屏控制区驻留时间，可选 2 / 4 / 6 / 10 秒。
- 全屏方向键支持短按后退/前进 10 秒，长按左键临时 0.5×、右键临时 2×，松开后恢复原倍速。
- 修复全屏侧边栏展开再收起后底部控制区失效的问题。
- 进度条关闭无意义的数字 Tooltip，接入实际解码帧预览；拖动事件改为捕获已处理的 Slider/Thumb 指针事件，提高拖动预览可靠性。
- Playback 运行时升级至 0.2.3，新增后端无关的帧抓取能力。
- 更新管理页的 Eizo 与 Metadata 卡片继续共用统一列宽和按钮宽度。
- Metadata 卡片新增“发行说明”按钮；已检查更新时优先打开对应 Eizo.Metadata Release，否则打开 Metadata Releases 页面。

## 兼容性

- Windows 10 2004 / Windows 11，x64。
- 继续使用独立更新的 Eizo.Metadata 与 Eizo.Playback 组件架构。
