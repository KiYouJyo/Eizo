# Eizo v0.6.1

## アプリビジュアルアセット更新

0.6.1 では、Windows アプリアイコン、MSIX ビジュアルリソース、Microsoft Store 掲載アセットを一新します。既存の UI レイアウト、業務ロジック、機能は変更しません。

## 変更内容

- EXE、ショートカット、インストーラー向けのマルチサイズ `Eizo.ico` を更新。
- AppList、Square44、Square150、Square71、Square310、Wide、StoreLogo、SplashScreen と全 DPI／テーマ変種を置換。
- MSIX Manifest で AppList、Windows 10 互換タイル、スプラッシュ画面を有効化。
- Microsoft Store 用の正方形、ポスター、Super Hero 掲載アセットを追加。

## 互換性

- Windows 10 2004 / Windows 11、x64。
