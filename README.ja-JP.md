# 映蔵 Eizo

[简体中文](./README.md) · [English](./README.en-US.md)

**映蔵（Eizo）** は Windows 向けのネイティブメディアライブラリです。日本のアニメとドラマを第一に設計し、映画、TVシリーズ、その他の個人メディアにも対応します。

> 現在のフェーズ：リポジトリ基盤とローカライズ基盤の整備。

## プロダクト方針

- 日本アニメ・日本ドラマを優先したメディア認識とメタデータ体験
- ローカル、WebDAV、商用クラウドストレージを統一して扱うメディアソース層
- 自動メタデータ取得、作品関係、クール管理、視聴進捗
- 実績のあるオープンソース再生エンジンによる高品質な再生
- WinUI 3 によるネイティブ Windows 体験
- 简体中文・日本語・English の3言語対応

## 開発ロードマップ

Foundation → 日本メディア認識 → アニメメタデータ → 日本ドラマメタデータ → 再生 → ライブラリ UX → WebDAV → Streaming Gateway → 商用クラウドストレージ、の順に進めます。
