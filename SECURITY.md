# Security Policy

Please report security-sensitive issues privately through GitHub's security reporting / Security Advisory flow when available.

Do not disclose credentials, OAuth tokens, signing keys, private certificates, Microsoft Store publishing credentials, or reproducible security vulnerabilities in a public issue.

Security-sensitive areas include OAuth and cloud-drive authentication, WebDAV credentials, the local streaming gateway, HTTP header forwarding, token persistence, local credential storage, remote media URLs, updates, and package signing.

The repository ignore rules are a guardrail, not a substitute for reviewing commits before pushing them.
